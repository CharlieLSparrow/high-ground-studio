# Code of conduct

We want collaboration here to be candid, kind, evidence-driven, and safe.

## Expected behavior

- Critique the work and the evidence, not the person.
- Make assumptions visible and invite correction.
- Respect privacy, consent, authorship, and source provenance.
- Give specific, actionable review feedback.
- Make space for different experience levels and communication styles.
- Stop and escalate when a change may expose people or private work.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, sexualized attention, doxxing,
deliberate exposure of private material, retaliation, and sustained bad-faith
disruption are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through GitHub.
Do not put sensitive details in a public issue. Maintainers may edit or remove
content, close participation, restrict repository access, or escalate to GitHub
when needed.

This policy applies in repository issues, pull requests, reviews, discussions,
and project-related communication.
