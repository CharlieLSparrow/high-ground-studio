# Support

This repository is for product development and engineering collaboration.

## Use GitHub issues for

- reproducible bugs using synthetic or approved data;
- bounded feature proposals tied to a user workflow;
- documentation errors;
- developer setup and build failures;
- accessibility and UX defects.

Include the affected surface, commit, environment, exact reproduction, expected
result, actual result, and the proof artifact that is safe to share.

## Do not use GitHub issues for

- vulnerability details: follow [SECURITY.md](SECURITY.md);
- account recovery, billing, or private coaching matters;
- recordings, transcripts, manuscripts, credentials, or personal data;
- urgent production incidents containing private context.

Quipsly is in active beta. There is no guaranteed public support SLA. Maintainer
priority is data safety, authentication, release integrity, and workflows used
for real Capture, Nest, coaching, and High Ground Odyssey production.
