# Nest writing publication runway

Last updated: 2026-06-24

The writing publication runway connects Nest draft packets to Tower-style review
and publishing preparation. It does not publish, upload, schedule, replace
canonical manuscript text, or mutate source files.

## Command

```bash
./script/agentctl.sh writing-publication-runway
```

## Product rules

- Draft readiness is not human approval.
- Human approval is not external publication.
- External publication is not true until a real URL or provider receipt exists.
- Source files remain untouched.
- Draft packets may contain useful AI-assisted prose, but every packet preserves
  source trails and review requirements.
