# Active working goal: great shorts, not just exported shorts

The formal Codex goal tool still has the previous broad goal marked unfinished, so this document is the working steering target for the next product loop.

## Goal

Build Quipsly Studio into a shorts-first production loop that can create genuinely strong short-form content for YouTube Shorts, Instagram Reels, Facebook Reels, TikTok-style vertical platforms, LinkedIn, Patreon teasers, and site embeds.

## Primary proof lane

Use High Ground Odyssey Episode 1 as the immediate proving ground.

The goal is not merely to create technically valid clips. The goal is to create short videos that have a real chance of earning attention:

- Clear opening hooks.
- Strong pacing.
- Readable captions and safe text placement.
- Speaker-aware vertical crop.
- Solid audio.
- Platform-aware titles, descriptions, destinations, and reuse notes.
- Fast local export and review.

## Product principle

Quipsly should help us make better short-form work, not simply move cards through a process.

Approval state is secondary. Output quality is primary.

## Implementation priorities

1. Short candidate discovery and scoring.
2. Local export and listen/watch review.
3. Vertical crop and caption-safe presentation.
4. Transcript/caption assist.
5. Platform packaging.
6. Agent/human collaboration for first pass, refinement, and learning data.

## What success looks like

A human or Codex can open Studio, find the most promising clips, improve them, export real local files, inspect and listen to them, and prepare them for platform-specific posting without drowning in approval bureaucracy.
