# Mako's High Ground Odyssey Edit Desk

## Open it

1. Sign in to `nest.quipsly.com` with the account invited to High Ground Odyssey.
2. Open the High Ground Odyssey Nest.
3. Choose **Open episode editor**.
4. Pick the episode from the menu at the top.

There is no Save button. Each decision and note saves to the shared edit as soon as you make it.

## Make display decisions

Move the playhead to the moment a new choice should begin, then press:

| Key | Show |
| --- | --- |
| 1 | Charlie |
| 2 | Homer |
| 3 | Both |
| 4 | Skip this section |
| 5 | Charlie and the watched clip |
| 6 | Homer and the watched clip |
| 7 | Both hosts and the watched clip |

The choice continues until the next choice. You are not cutting or deleting any source file.

## Move around

| Key | Action |
| --- | --- |
| Space | Play or pause |
| [ | Move back one second |
| ] | Move forward one second |
| M | Write a note at the playhead |

Click or drag the timeline to move precisely. Every source monitor follows the same shared clock.

## Notes and tags

Press `M`, write what should happen, and optionally add comma-separated tags such as `intro`, `drop`, `reaction`, `short`, or `fix audio`.

Notes are attached to the exact episode time and record who wrote them and when.

## What the labels mean

- **Protected sync baseline**: the source videos, audio, offsets, and proxies. Your display decisions cannot damage it.
- **Shared editor cut**: the current collaborative set of decisions.
- **Revision**: the number of saved operations on the shared cut.
- **Source missing a proxy**: the edit data is safe, but Charlie/Codex needs to prepare that source for browser playback.

If the simple desk cannot express a complex edit, leave a timestamped note. The native Studio team can handle it without losing your surrounding decisions.
